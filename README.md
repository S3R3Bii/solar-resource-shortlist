# Check a solar-resource shortlist before treating it as a project shortlist

Year-to-year radiation changes and missing observations can affect which locations look strongest. This study will compare simple resource-ranking rules on a fixed set of Southwest grid points, keeping resource screening separate from land suitability, plant output and financial feasibility.

**Current state: protocol before daily-data collection.** No ranking result, return or actual generation is established. The [protocol](PROTOCOL.md) fixes the locations, years, source, forecast information boundary, candidate rules, missing-day stress cases and checks. Independent program manuscripts are authorized after checks; formal-publication projects remain private.
